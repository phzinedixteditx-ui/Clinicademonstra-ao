## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico & Acessibilidade (WCAG AAA)**
- **Tailwind CSS** (Design System com paleta institucional Deep Navy & Petroleum)
- **FontAwesome 6** (Iconografia)
- **Google Fonts** (*Plus Jakarta Sans*)
- **Schema.org / JSON-LD** (Dados Estruturados para SEO Local `MedicalBusiness`)
- **JavaScript ES6+** (Gaveta do Menu Mobile & Observer de Animações no Scroll)
